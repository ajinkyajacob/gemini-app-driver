Gemini App Driver — what an agent can do

Every action below is exposed twice: as an MCP tool (for agents) and as a CLI command (for humans and scripts).

CLI

gemini-app-driver <cmd>

Two planes of action

Control plane

Manages the Gemini process and the patched archive. Uses the filesystem, taskkill/spawn, and the DevTools port.

Data plane

Talks to the live gemini.google.com page over CDP: composer, send button, message DOM, screenshots.

Available actions

control read-only changes conversation
Runtime
access

gemini_setupcontrol

setup [--port]

Patches app.asar, restarts Gemini with the DevTools port, waits for the page. Re-run after app updates.

gemini_restorecontrol

restore

Puts the original app.asar back, restarts the app normally, closes the debug port.

gemini_statusread

status

Version, patch state, running/CDP state, current conversation, model, streaming, message count.

Conversation
management

gemini_new_chatwrite

new-chat [--mode chat|task]

Navigates to a fresh /app conversation and returns its URL; optionally selects Chat or Task mode.

gemini_modewrite

mode [chat|task]

Reads or switches the segmented Chat/Task control. Task reframes the composer ("Describe a task") and swaps suggestions. New chats only.

gemini_readread

read [--json]

Ordered {role, text} transcript of the current conversation, plus model and streaming state.

gemini_conversationsread

conversations [--limit]

Sidebar conversations as {id, title, href}.

gemini_openwrite

open <id|title>

Opens a conversation by id or partial title, then returns its messages.

Composer
toolbar

gemini_modelwrite

model [name]

Lists models (3.5 Flash-Lite, 3.8 Flash, 3.1 Pro, 4 Argon) and switches the selected one.

gemini_thinkingwrite

thinking [low|medium|high]

Reads or switches the Thinking level submenu under the model picker.

gemini_toolsread

tools

Lists Upload files, Add from Drive, More uploads, Create image, Create video, More tools and their on/off state.

gemini_toolwrite

tool <name> [on|off]

Toggles Create image, Create video, Create music, Canvas, Deep Research, Guided Learning, Personal Intelligence.

gemini_attachwrite

attach <path...>

Uploads local files: media goes to the image/video input, documents/code go to the document input.

Driving the
chat

gemini_askwrite

ask [--new-chat] [--mode chat|task] [--thinking] [--tool] [--attach] <prompt>

Types a prompt, sends it, waits for streaming to finish, returns {answer, images, conversationId, url, timedOut}.

gemini_stopcontrol

stop

Clicks the in-app Stop button on a generation that is still streaming.

gemini_screenshotread

screenshot [path]

Captures the rendered page as a PNG and returns it as an MCP image (+ saved path).

What gemini_ask does internally

1 ensure CDP→ 2 focus emulation→ 3 mode (optional)→ 4 model / thinking (optional)→ 5 tools (optional)→ 6 attachments (optional)→ 7 clear composer→ 8 insert prompt→ 9 click send→ 10 watch user-query→ 11 wait for Stop to vanish→ 12 text/image stable→ 13 return answer

Guard rails

Actions that write to the conversation require the app to be running with the debug port; the driver auto-runs the equivalent of setup on first use, which restarts Gemini. Destructive/runtime actions (setup, restore) are explicit tools so an agent can be asked before restarting the app. ask returns promptly with stopped: true if a generation is cancelled, instead of hanging.

Chat/Task mode is a segmented control that only exists on a new chat; status reports mode/modeOptions (null in an existing conversation). It is separate from the model picker (model, e.g. Argon) and the thinking level.

Attachments and enabled tools persist in the composer until the next send; a new chat resets them. When the answer is an image, ask returns images instead of text.
